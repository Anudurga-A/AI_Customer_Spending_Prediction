# AI-Based Customer Spending Prediction

## About the Project
AI-Based Customer Spending Prediction is a Machine Learning project developed using Python. It analyzes customer details and predicts their spending category as Low, Medium, or High.

## Objectives
- Analyze customer spending patterns.
- Clean and process customer data.
- Visualize customer information using graphs.
- Train Machine Learning models.
- Predict customer spending categories.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier

## Dataset Features
- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

## Project Modules
1. Data Collection
2. Data Cleaning
3. Data Analysis
4. Data Visualization
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Customer Spending Prediction
9. Model Saving

## Spending Categories
- Low: Score 33 or below
- Medium: Score 34 to 66
- High: Score 67 to 100
