# AI-Based Customer Spending Prediction

## Project Description
This project uses Machine Learning to predict customer spending categories.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier

## Spending Categories
- Low
- Medium
- High

## Project Modules
1. Data Collection
2. Data Cleaning
3. Data Visualization
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Customer Prediction
8. Business Insights

## How to Run
Install the required libraries:

pip install -r requirements.txt

Run the project:

python customer_spending.py

## Output
The project generates graphs, model comparison,
feature importance and business insight reports.
